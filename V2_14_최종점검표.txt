샌드위치 경매 CEO · V2.14 최종 현장점검표

A. 배포 후 1회 확인
□ GitHub Actions 최신 배포가 Success인지 확인
□ 첫 화면 / 교사용 / 학생용 모두 V2.14 표기 확인
□ 교사용 상단 Firebase 연결됨 확인
□ 새 수업방 만들기(기존 V2.13 테스트방 재사용하지 않음)
□ 학생 QR과 방 코드 생성 확인

B. 설정 확인
□ 학생 15명, 5조, 조별 30,000원
□ 일반 경매 30초
□ 메인: 닭가슴살 / 참치 / 완숙 삶은달걀 / 크래미 / 고구마무스
□ 기본·공용: 식빵 / 양상추 / 햄 / 마요네즈 / 케첩 / 허니머스타드 / 생수 / 감자샐러드(공용 선택)
□ 추가: 치즈 / 토마토 / 피클 / 크림치즈 / 파인애플
□ 콜라 업그레이드 재고 2조분

C. 기능 리허설
□ 1~5조 대표폰 접속 완료
□ 메인 선택 5/5 → 단독 자동낙찰 / 경쟁입찰 / 실패조 재선택
□ 추가재료 참여/패스 5/5 실시간 반영(새로고침 없이)
□ 응답 확정 → 입찰 대상과 조 번호 일치
□ 입찰 → 낙찰 → 재고 감소 → 예산 차감 일치
□ 최고가 동점 → 동점 조만 10초 재입찰
□ 같은 가격 재입찰 가능 → 다시 동점이면 추첨
□ 콜라 업그레이드 팀당 최대 1회
□ 경매 종료 → 학생 2단계 자동 이동
□ 2~7단계 작성 → Padlet 링크 열림 / 요약 복사
□ 수업방 종료 → 학생 입장화면 자동 복귀

D. 수업 당일 운영
□ 각 조 대표폰 1대 고정
□ 학생은 QR로 접속, 자기 조만 선택
□ 화면 이상 시 반복 새로고침 금지, 선생님 호출
□ 종이 활동지/기록표를 비상 백업으로 준비
