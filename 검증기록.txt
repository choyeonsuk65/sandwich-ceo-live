2안 V2.2 Firebase 실연결본 검증기록

- firebase-config.js: 사용자가 Firebase Console에서 복사한 실제 설정값 반영
- appId 원문 대조 반영
- teacher.js: 현재 게시된 Realtime Database 규칙에서 동작하도록 상위 rooms/teams/bids/participation 전체읽기를 제거하고 세부 경로 읽기로 수정
- teacher.js / student.js / common.js: Node 문법검사 대상
- firebase-rules.json: JSON 형식검사 대상, 현재 Firebase에 게시한 규칙과 동일
- 실제 다중기기 실시간 동작은 GitHub Pages 공개 후 교사/학생 기기로 최종 확인 필요
